# 야유회 퀴즈 빙고

폰 브라우저로 접속해서 하는 4×4 퀴즈 빙고입니다. 앱 설치나 회원가입 없이, 링크나 QR만으로 참가할 수 있어요.
Firebase(Realtime Database + 익명 로그인)와 Vercel로 돌아갑니다.

## 파일
- `index.html`: 앱 전체 (참가자 화면 + 진행자 화면)
- `database.rules.json`: Firebase 보안 규칙 (참가자가 정답을 볼 수 없게 막아 둠)

## 준비 (한 번만)

### 1. Firebase
딥시크루 때 만든 프로젝트를 그대로 써도 되고, 새 프로젝트를 만들어도 됩니다. 이 앱은 DB 안의 `bingo/` 경로만 써서 기존 데이터와 섞이지 않아요.

1. **Authentication → 로그인 방법 → 익명** 사용 설정
2. **Realtime Database** 만들기 (위치는 asia-southeast1 추천)
3. **Realtime Database → 규칙** 탭에 `database.rules.json` 내용 붙여 넣고 게시
   - 기존 프로젝트에 이미 규칙이 있다면, `"rules": { ... }` 안에 `"bingo": { ... }` 블록만 추가하세요.
4. **프로젝트 설정 → 내 앱 → 웹 앱**의 `firebaseConfig` 값을 `index.html` 위쪽 `FIREBASE_CONFIG`에 붙여 넣기
   - `databaseURL`이 꼭 있어야 해요. 없으면 Realtime Database 화면 상단 주소(https://...firebasedatabase.app)를 넣으세요.

### 2. Vercel 배포
- 이 폴더를 그대로 배포하면 됩니다. (`vercel` 명령어 또는 Vercel 대시보드에서 폴더 업로드)
- 배포 후 Firebase **Authentication → 설정 → 승인된 도메인**에 Vercel 주소(`xxx.vercel.app`)를 추가하세요.

## 진행 방법
1. 진행자가 사이트를 열고 **새 게임 만들기** → 4자리 코드가 생깁니다.
2. **문제 편집** 탭에서 16문제(OX/객관식, 정답)를 넣고 저장. (예시 문제 16개가 기본으로 들어 있어요)
3. **참가 링크** 탭의 QR이나 링크를 공유. 참가자는 이름만 입력하면 바로 시작.
4. **순위 현황** 탭에서 1등부터 통과 순서, 진행 중인 사람의 상황을 실시간으로 봅니다.

### 꼭 알아둘 것
- **채점은 진행자 화면이 합니다.** 게임 중에는 진행자 화면을 켜 두세요. 꺼져 있으면 참가자 화면이 "채점 중…"에서 멈췄다가, 다시 켜면 그때 채점돼요.
- 등수는 Firebase 서버 시각 기준이라 폰 시계가 달라도 공정합니다.
- 진행자는 **게임을 만든 브라우저**로만 진행자 화면에 들어갈 수 있어요. 같은 폰/브라우저로 사이트를 다시 열면 "이 기기에서 만든 게임"에 목록이 있어요.
- 리허설 후에는 **기록 초기화**로 참가자와 순위를 지우면 됩니다. 문제는 그대로 남아요.
